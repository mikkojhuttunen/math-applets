# Esittelysivu (demo)

A small demo site for showing the project: pick a school level (luokat 1–3, 4–6, 7–9, lukio pitkä, lukio lyhyt), a season (syksy, talvi, kevät) and a topic, then do a round of five working exercises with feedback.

Published at `https://mikkojhuttunen.github.io/math-applets/demo/` once merged into `main`.

- `index.html`, `css/demo.css`, `js/demo.js`: the page. Screens are addressed by the hash, e.g. `demo/#7-9/talvi/2`, so links can be shared.
- `js/plan.js`: logic without the DOM (topic items, season of a date, hash routing).
- `data/plan.json`: levels, seasons and topics, written by hand. A topic with `goal` (and optional `grade`) takes its exercises from the practice pages' banks; one with `set` takes them from `data/lukio_items.json`. The season split is a proposal for the demo.
- `data/lukio_items.json`: 42 hand-written upper secondary exercises (no lukio bank exists yet), generated by `tools/build_lukio_items.py`.
- The exercise engine (loading, checking, feedback, rounds, column view) is imported read-only from `../harjoittele/js/`. The demo shows draft items and draft feedback, like the practice page's `?luonnokset=1` preview.

Checks, from `demo/`:

    npm test
    NODE_PATH=$(npm root -g) node tools/browser_test.js

The second prints `DEMO TEST OK` (start screen, every level, season and topic, and one full round per level at 360 px). Locally: `python3 -m http.server 8000` in the repo root, then `http://localhost:8000/demo/`.
